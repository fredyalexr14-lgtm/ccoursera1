# Guía de Contribución

Se aceptan todas las contribuciones, informes de errores, correcciones de errores, mejoras en la documentación, mejoras y ideas.

## Cómo contribuir
- Haz un fork del repositorio.
- Crea una rama para tu contribución.
- Realiza los cambios necesarios.
- Envía un pull request para revisión.

## Informes de errores
Por favor, utiliza la sección de *Issues* para reportar cualquier error encontrado.

## Correcciones y mejoras
- Se aceptan parches y soluciones propuestas.
- Se agradecen mejoras en la documentación y nuevas ideas para el proyecto.
